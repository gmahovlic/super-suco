# Super Suco de Limão 🍋

Calculadora de super suco de limão. Site 100% estático (HTML + CSS + JS puro).

Proporção: 15 g de casca → 10 g de ácido cítrico, 5 g de ácido málico e 250 ml de água.

## Publicar no GitHub Pages
